# Marketing, made clear

A personal English marketing study companion for Dr. Rehab Moustafa, Brand Manager.

## Study

Open the site and select **Practice** for the starting diagnostic, topic quizzes, timed practice and mistake review. There are 53 illustrated lessons, 196 original multiple-choice questions with 784 option explanations, and six applied mini-cases. The complete workbook is embedded in the main book; its standalone page is also retained.

Three fixed practice papers add 30 new questions each. Select 30, 45 or 60 minutes, change answers, flag questions and move freely before submission. Answers save immediately; the timer continues after closing or refreshing. Results and explanations appear on submission or expiry. Retakes reuse the same questions. Suggested timing is editorial, not official CIM timing.

Download **complete-book.pdf** for the combined reading book, workbook, papers and separate explanations. Both HTML pages also support **Print / save PDF**.

This is original notes-based teaching material, not an official CIM publication, authorised exam paper, full-syllabus mock, or pass prediction. Qualification and module alignment remain unconfirmed.

## Privacy and storage

The site and repository are public. Search-engine indexing is discouraged, not prevented or access-controlled. No personal photos or original handwritten scans are included. There is no app backend, analytics integration or account system. Quiz results and reading progress stay in the current browser; they do not sync between devices. GitHub receives ordinary web-hosting requests. Exporting a progress record saves a local JSON file; importing records is not supported.

## Deployment

This repository contains only the reviewed static publishing bundle and the generated complete study PDF. GitHub Pages publishes the root of the main branch, with Jekyll disabled. No dependencies, credentials or build step are required on the host. Content maintenance sources and the original handwritten PDF remain outside this repository.

After an update, verify the home page, a completed quiz, refresh/resume, workbook links and mobile layout. To undo a bad update, revert the relevant commit and push to main; to unpublish, disable Pages in repository settings. Removing a public site cannot retract copies already downloaded.
